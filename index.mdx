Chaotic Command helps Discord server owners and administrators create a starting structure of roles, categories, and channels. You choose a template, inspect a preview, and explicitly confirm before the app sends changes to Discord.

Use these guides to understand what the app can do today, who can operate it, and what to check before applying a setup. Chaotic Command is an additive setup tool. It does not replace your decisions about role permissions, channel privacy, moderation, or ongoing community management.

## What Chaotic Command currently provides

Chaotic Command offers Community, Gaming, and Support setup templates. It previews proposed roles and channels, reuses exact matches, creates missing items after confirmation, and provides shared server notes for current server managers.

New roles start with zero permissions and are not assigned to members. Existing roles are reused without changing their permissions. New channels inherit category or server visibility, so an administrator must review access settings separately.
