The Chaotic Command bot needs permission to create the roles, categories, and channels listed in a setup preview. You can install it from the server-specific link shown in Chaotic Command.

## Requirements

- Sign in with a Discord account that owns the server or has Manage Server or Administrator permission.
- Be able to add the bot to the server.
- Be prepared to place the bot's role above the roles it may create.

## Install the bot

<Steps>
  <Step title="Select your server">
    Sign in to Chaotic Command and choose the server you want to prepare.
  </Step>
  <Step title="Open the installation link">
    If the app reports that the bot is not ready, use the installation link displayed for the selected server.
  </Step>
  <Step title="Review Discord permissions">
    The bot requests Manage Channels and Manage Roles. It does not request Administrator. Stop if the authorization screen requests permissions beyond the documented scope.
  </Step>
  <Step title="Complete installation">
    Authorize the bot for the intended server.
  </Step>
  <Step title="Check role position">
    In Discord server settings, move the bot's role above the roles that Chaotic Command will create. Discord role hierarchy can prevent a bot from managing roles below its own role.
  </Step>
  <Step title="Return to Chaotic Command">
    Reselect the server. The app checks bot readiness and reports the server's current channel and role counts when the bot is ready.
  </Step>
</Steps>

If the bot is still not ready, see [troubleshooting](/troubleshooting). Do not grant Administrator as a workaround.
