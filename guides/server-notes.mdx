Chaotic Command includes a notes area for the selected Discord server. Use it to keep short operational reminders that current server managers can revisit.

## Save notes

1. Sign in to Chaotic Command.
2. Select the server.
3. Enter or update the notes in the server notes area.
4. Select the save action and wait for the saved confirmation.

The notes are associated with the selected server. They are available only to people who currently have permission to manage that server.

## Keep notes safe

Do not store passwords, bot tokens, Discord credentials, recovery codes, private member information, or other sensitive data in server notes. Use a password manager or another approved secure system for secrets.

Notes do not activate automations. Saving a reminder does not create a task, send a message, assign a role, or change anything in Discord.

If you cannot save notes, confirm that you selected the correct server and still have Manage Server or Administrator permission.
